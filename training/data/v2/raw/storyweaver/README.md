# StoryWeaver Raw Santali-Hindi Dataset

## Overview
This directory contains raw narrative materials and book catalogs extracted from StoryWeaver (Pratham Books / Suchana Community) in Santali (Ol Chiki script) and Hindi (Devanagari script).

## Status: Raw Data / Manual Alignment Required
In accordance with Phase 2B Step 4 rules:
- Hindi and Santali books from StoryWeaver are not pre-aligned at the sentence level by the upstream platform.
- In order to strictly avoid fabricating machine alignment without native speaker verification, these materials are held in 	raining/data/v2/raw/storyweaver/ for manual / linguist-verified sentence alignment in Phase 2C.
- **Zero fabricated sentence pairs** have been admitted to intermediate/ or cleaned/.
