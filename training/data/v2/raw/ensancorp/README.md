# EnSanCorp (English-Santali Parallel Corpus) Raw Registry

## Dataset Overview
- **Citation:** Ghosh, S., et al. (2022). *EnSanCorp: An English-Santali Parallel Corpus for Neural Machine Translation*.
- **Volume:** 5,930 English-Santali aligned sentence pairs (39,646 English tokens, 39,936 Santali tokens).
- **Languages / Scripts:** English (ng_Latn) $\leftrightarrow$ Santali (sat_Olck).
- **License:** Non-commercial academic research license.

## Acquisition & Technical Status
1. **Public Download Status:** Unavailable via open automated HTTP download or public Zenodo/GitHub repository. Access requires direct correspondence with the research authors (International Journal of Applied Mathematics / ResearchGate).
2. **Phase 2B Policy Compliance:** In accordance with Phase 2B Step 6 instructions:
   - English-Santali sentence pairs must NOT be machine-translated into Hindi to create pseudo-parallel Hindi-Santali data.
   - Any future English-pivot generation will be conducted as a separate controlled experiment under human linguistic supervision.
   - Acquired raw bitext will reside in this directory without automated Hindi synthetic translation.
