## 🛡️ Root Cause & Technical Fix Summary

1. **Online SpeechRecognizer Fallback Bypass**: Replaced system SpeechRecognizer priority in VoiceInputManager.kt with direct local IndicConformerHindiAsr routing, eliminating Google Cloud API calls when offline.
2. **NeMo STFT Log-Mel Spectrogram Feature Extraction**: Replaced random noise placeholder with real-time pre-emphasized center-padded 400-sample Hann windowing, 257-bin DFT power spectrograms, 80-band Slaney log-mel filtering, and per-feature z-score scaling in Kotlin.
3. **ONNX loatBuffer Row-Major Indexing**: Fixed implicit Java ClassCastException by reading ONNX Runtime tensor logits directly via outputTensor.floatBuffer.
