# Multilingual Translation Datasets (`translation/data/`)

This directory contains evaluation datasets for Hindi $\rightarrow$ Santali (`hin_Deva` $\rightarrow$ `sat_Olck`) neural machine translation.

---

## 1. IN22-Conv Parallel Benchmark
* **Source Dataset**: `C:\Users\jesva\Downloads\translation-data\hi_sat_in22.csv`
* **Sentence Pairs**: **1,503 parallel sentences**
* **Source Language**: Hindi (`hin_Deva`, Devanagari script)
* **Target Language**: Santali (`sat_Olck`, Ol Chiki script)
* **Description**: Primary baseline quantitative benchmark for general conversational Hindi $\rightarrow$ Santali translation.
